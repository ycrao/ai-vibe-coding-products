
# 端口扫描器（Python 多线程版本）

本项目提供一个简单的多线程端口扫描脚本 `port_scanner.py`，支持：

- 指定目标主机（IP 或域名）
- 扫描指定端口范围
- 扫描常见端口快捷选项
- 多线程并发扫描
- 命令行参数控制超时时间和线程数
- 将扫描结果输出到文件
- 在终端显示扫描进度条

> 说明：脚本使用了 Python 类型标注中的 `list[int]` 语法，推荐 Python 3.9 及以上运行。

## 环境准备

- Python 版本：推荐 **Python 3.9+**
- 依赖库：仅使用标准库（`argparse`、`socket`、`concurrent.futures`），无需额外安装第三方包。

## 基本用法

在项目根目录（包含 `port_scanner.py` 的目录）执行：

```bash
python port_scanner.py -H <主机> [其他参数]
```

示例：

```bash
# 扫描本机 1-1024 端口
python port_scanner.py -H 127.0.0.1 -p 1-1024
```

## 命令行参数说明

运行 `-h` 查看帮助：

```bash
python port_scanner.py -h
```

主要参数：

- `-H, --host`（必选）
  - 目标主机，可以是 IP 或域名。
  - 示例：`-H 127.0.0.1`、`-H scanme.nmap.org`

- `-p, --ports`（可选）
  - 指定端口或端口范围：
    - 单个端口：`-p 80`
    - 范围：`-p 1-1024`
  - 如果只指定 `-p`，脚本仅扫描这一范围。

- `--common`（可选）
  - 只扫描内置的常见端口列表，例如：`22, 80, 443, 3306, 3389, 8080` 等。
  - 可以与 `-p` 同时使用，最终会把两部分端口合并去重后一起扫描。
  - 示例：
    - 仅常见端口：`python port_scanner.py -H 127.0.0.1 --common`
    - 常见端口 + 8000–8100：`python port_scanner.py -H 127.0.0.1 --common -p 8000-8100`

- `-t, --threads`（可选）
  - 最大线程数（并发扫描的线程数量），默认：`100`。
  - 数值越大，扫描越快，但对系统和网络的压力也越大。
  - 示例：`-t 200`

- `-T, --timeout`（可选）
  - 单个端口连接超时时间（秒），默认：`1.0`。
  - 网络较慢或跨公网时可以适当调大，例如 `2.0` 或 `3.0`。
  - 示例：`-T 2.0`

- `-o, --output`（可选）
  - 将扫描结果写入指定文件。
  - 示例：`-o result.txt`

## 常见用法示例

### 1. 扫描指定端口范围

```bash
# 扫描 192.168.1.10 的 1-1024 端口
python port_scanner.py -H 192.168.1.10 -p 1-1024
```

### 2. 扫描常见端口

```bash
# 扫描本机常见端口（如 22、80、443、3306 等）
python port_scanner.py -H 127.0.0.1 --common
```

### 3. 常见端口 + 自定义范围

```bash
# 常见端口 + 8000–8100
python port_scanner.py -H 127.0.0.1 --common -p 8000-8100
```

### 4. 增大线程数和超时时间

```bash
# 使用 200 线程，超时 2 秒
python port_scanner.py -H scanme.nmap.org -p 1-1024 -t 200 -T 2.0
```

### 5. 将结果写入文件

```bash
# 扫描并将开放端口写入 result.txt
python port_scanner.py -H 192.168.1.10 -p 1-65535 -t 300 -o result.txt
```

- 如果发现开放端口，文件内容类似：

  ```text
  22
  80
  443
  ```

- 如果未发现开放端口，内容为：

  ```text
  未发现开放端口。
  ```

## 进度条说明

扫描过程中会在终端显示类似的进度条：

```text
开始扫描 127.0.0.1，共 13 个端口，最大线程数 50，超时 0.5s ...
扫描进度: [########################################] 13/13 (100.0%)
```

- `[]` 中的 `#` 表示已完成比例，`-` 表示未完成部分。
- `13/13` 表示已完成任务数量 / 总任务数量。
- `100.0%` 表示整体进度百分比。

扫描完成后会输出汇总结果（开放端口列表或“未发现开放端口。”）。

## 安全与合规提醒

- 在实际环境中进行端口扫描前，请确认你对目标主机和网络拥有合法授权。
- 不要扫描未授权的生产环境或陌生网站，以避免触犯相关法律法规或服务条款。
- 建议在实验环境、自己控制的服务器或明确允许的目标上使用本工具。
